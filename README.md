# My Personal Portfolio

As I began to build more projects to show recruiters my skills, I needed a place to share my projects. I've tried using various platforms to try building a portfolio, but I kept losing my motivation to do so. I decided to finally build one during a computer science lab; once I finished my required labwork I wanted to create something computer-related for the rest of the lab period. I started building this website using HTML and W3.CSS, a modern framework that can create responsive and stylized pages.

Contained in my website are three pages. The landing page behaves like my resume with slight alterations, and this is where I highlight my schooling, professional, and leadership experience. I use the second page as the portfolio itself, providing links to my projects and giving brief descriptions of them. Third, I included a contact form with ways visitors can connect with me in case anyone visiting the page has questions, comments, concerns, and suggestions. I included a headshot, biography, and my skills on the side of all three pages.

Visit my portfolio website [here](https://samanthanadler.github.io/)!
